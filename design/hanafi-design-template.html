1. Colours

All values are CSS variables in :root. A relationship colour is used for the box band and border; the matching tint (9 % over white) is the box background.

2. Box types

Class hb-box + data-rel (com / foot / abr / takh / comb). Base text = hb-box--root (no band). See-page box = hb-box--ref. In the real diagram boxes are position:absolute; hb-box--static is used here only to show them side by side.

3. Connected sample (rails, buses, indented stack)

Lines are 2 px #7E8A84, straight, square caps. A parent drops to a horizontal bus, which drops to each child column. A column of several books uses a vertical rail on its left with short ticks, and nested books are indented 24 px.

4. Combined work (bracket) and “combined into” arrow

Left: on the Combined Works page the sources sit in a row above the new book and are joined by a bracket. Right: on the overview page the same relation is a dotted violet arrow (.hb-combine).
